# Scribbly — AI Handwriting Recognition

## Quick Start

### Windows
Double-click `start.bat`

### Mac / Linux
```bash
bash start.sh
```

Then open **http://localhost:5173**

---

## How it works

- **Google Handwriting Input API** — stroke-based recognition, zero API key
- Writes on a smooth dark-themed canvas, auto-converts 1 second after you lift the pen
- Alternatives panel shows up to 6 recognition candidates
- Save, speak, copy results — all in-browser

## Requirements
- Node.js 18+ — https://nodejs.org
- Internet connection (for Google recognition API)
